# 采购记账模块使用帮助文档

## 模块概述

采购记账模块是wimoor ERP系统中用于管理采购相关财务记录的核心功能模块。该模块提供了完整的账户管理、记账操作、数据统计和报表分析功能，帮助企业实现采购财务的精细化管理。

## 主要功能

### 1. 账户管理

#### 1.1 查看账户列表
- **位置**：概览标签页左侧
- **功能**：显示所有已创建的账户及其余额信息
- **操作**：
  - 点击账户卡片可查看该账户的详细收支数据
  - 账户卡片显示账户名称、支付方式和当前余额
  - 默认账户会显示"默认"标签

#### 1.2 添加新账户
- **操作步骤**：
  1. 在账户列表底部点击"添加账户"按钮
  2. 在弹出的对话框中输入账户名称
  3. 选择账户类型（支付方式）
  4. 点击"确认"按钮完成创建

#### 1.3 账户操作
- **重命名**：点击账户卡片右上角的更多菜单，选择"重命名"
- **删除**：点击账户卡片右上角的更多菜单，选择"删除"
- **设为默认**：点击账户卡片右上角的更多菜单，选择"设为该支付方式默认卡"
- **取消默认**：点击账户卡片右上角的更多菜单，选择"取消该支付方式默认卡"

#### 1.4 恢复已删除账户
- **操作步骤**：
  1. 点击账户列表标题旁的"查看删除列表"按钮
  2. 在弹出的对话框中查看已删除的账户
  3. 点击对应账户的"恢复"按钮

### 2. 记账操作

#### 2.1 新建记账
- **位置**：记账标签页左侧
- **操作步骤**：
  1. 选择账户：从下拉列表中选择要记账的账户
  2. 选择记账类型：
     - 收入：资金流入
     - 支出：资金流出
  3. 选择收支项目：从预设的费用类型中选择
  4. 输入金额：填写具体的金额数值（必须为正数）
  5. 填写备注：可选，添加记账说明
  6. 点击"生成记账"按钮完成记账

#### 2.2 查看记账记录
- **位置**：记账标签页右侧
- **功能**：显示所有记账记录的列表
- **显示字段**：
  - 日期：记账时间
  - 账户：记账所属账户
  - 记账类型：收入/支出
  - 收支项目：费用类型名称
  - 金额：记账金额
  - 备注：记账说明

#### 2.3 筛选记账记录
- **日期范围**：选择开始和结束日期
- **账户筛选**：选择特定账户
- **类型筛选**：收入/支出
- **收支项目筛选**：选择特定费用类型
- **操作**：点击"查询"按钮应用筛选，点击"重置"按钮清除筛选条件

#### 2.4 撤销记账
- **操作步骤**：
  1. 在记账记录列表中找到要撤销的记录
  2. 点击该记录右侧的"撤销"按钮
  3. 在确认对话框中点击"确认"按钮

### 3. 数据统计

#### 3.1 收支统计图表
- **位置**：概览标签页右上角
- **功能**：以折线图形式展示收支趋势
- **操作**：
  - 点击日期选择器可切换查看年/月数据
  - 图表显示收入和支出两条趋势线
  - 鼠标悬停可查看具体数值

#### 3.2 支出项分布图表
- **位置**：概览标签页右上角
- **功能**：以饼图形式展示各项支出的占比
- **操作**：
  - 点击日期选择器可切换查看年/月数据
  - 鼠标悬停可查看具体金额和百分比

#### 3.3 收支明细表格
- **位置**：概览标签页下方
- **功能**：显示详细的收支记录
- **特点**：
  - 支持按日期汇总显示
  - 可展开查看每日详细记录
  - 支持导出功能
  - 支持搜索功能

### 4. 费用项管理

#### 4.1 查看费用项列表
- **操作**：在概览标签页点击"费用项管理"按钮
- **功能**：显示所有已创建的费用类型

#### 4.2 添加费用项
- **操作步骤**：
  1. 在费用项管理对话框中点击"添加费用类型"按钮
  2. 在新增行中输入费用名称
  3. 点击"保存"按钮

#### 4.3 编辑费用项
- **操作步骤**：
  1. 在费用项列表中点击对应费用项的"编辑"按钮
  2. 修改费用名称
  3. 点击"保存"按钮

#### 4.4 删除费用项
- **操作步骤**：
  1. 在费用项列表中点击对应费用项的"删除"按钮
  2. 确认删除操作

### 5. 支付方式管理

#### 5.1 设置支付方式顺序
- **操作**：点击账户名称旁的编辑图标
- **功能**：通过拖拽调整支付方式的显示顺序
- **操作步骤**：
  1. 在弹出的对话框中拖拽支付方式条目
  2. 调整到满意顺序后点击"保存"按钮

### 6. 数据导出

#### 6.1 导出收支明细
- **操作**：在概览标签页点击"导出"按钮
- **功能**：将当前筛选条件下的收支记录导出为Excel文件
- **文件格式**：.xlsx

## 使用场景示例

### 场景1：日常采购记账
1. 进入采购记账模块，切换到"记账"标签页
2. 选择对应的采购账户
3. 选择记账类型为"支出"
4. 选择收支项目为"采购成本"
5. 输入采购金额
6. 填写备注信息（如供应商名称、采购单号等）
7. 点击"生成记账"完成记录

### 场景2：月度财务分析
1. 进入采购记账模块，切换到"概览"标签页
2. 查看左侧账户余额总览
3. 在右上角图表中选择"月"视图
4. 分析本月收支趋势和支出分布
5. 在下方表格中查看详细记录
6. 如需导出数据，点击"导出"按钮

### 场景3：账户管理
1. 添加新账户：点击"添加账户"按钮，填写账户信息
2. 设置默认账户：选择常用账户，设置为默认
3. 调整账户顺序：通过拖拽调整账户显示顺序
4. 删除不再使用的账户：选择删除，需要时可恢复

## 注意事项

1. **金额输入**：金额必须为正数，系统会自动验证
2. **必填字段**：账户、记账类型、收支项目、金额为必填项
3. **撤销限制**：只有手动记账的记录可以撤销，系统自动生成的记录无法撤销
4. **数据安全**：删除的账户可以在"查看删除列表"中恢复
5. **权限控制**：部分操作可能需要相应权限

## 常见问题解答

### Q1：如何查看某个账户的详细收支记录？
A1：在概览标签页点击左侧账户卡片，右侧会自动显示该账户的统计数据和明细记录。

### Q2：记账时选错了账户怎么办？
A2：可以在记账记录列表中找到该记录，点击"撤销"按钮删除后重新记账。

### Q3：如何添加新的费用类型？
A3：在概览标签页点击"费用项管理"按钮，在弹出的对话框中点击"添加费用类型"按钮。

### Q4：删除的账户能恢复吗？
A4：可以，点击账户列表标题旁的"查看删除列表"按钮，在弹出的对话框中点击"恢复"按钮。

### Q5：如何导出记账数据？
A5：在概览标签页的收支明细表格上方点击"导出"按钮，系统会生成Excel文件供下载。

### Q6：为什么有些记账记录无法撤销？
A6：系统自动生成的记账记录（如关联单据产生的记录）无法手动撤销，需要在原单据中进行处理。

## 技术说明

- **数据刷新**：账户信息和统计数据会自动刷新
- **分页支持**：记账记录支持分页显示，可调整每页显示条数
- **响应式设计**：界面适配不同屏幕尺寸
- **实时计算**：账户余额会根据记账操作实时更新
