## 1. 模块概述

结转损益模块是财务会计期末处理的核心功能，用于将损益类科目的余额结转到"本年利润"科目，以便计算本期经营成果。该模块支持自动结转费用类科目、本年利润以及以前年度损益调整，确保财务数据的准确性和完整性。

## 2. 功能说明

### 2.1 核心功能

- **费用类科目结转**：将科目编码以5开头的费用类科目（如销售费用、管理费用等）余额结转到目标科目
- **本年利润结转**：将"本年利润"科目的余额结转到"未分配利润"科目
- **以前年度损益调整**：将"以前年度损益调整"科目的余额结转到指定科目
- **凭证自动生成**：根据结转逻辑自动生成会计凭证
- **灵活配置**：支持自定义结转周期、结转方式、凭证设置等

|---------|---------|--------|

### 3.2 结转步骤

#### 第一步：费用类科目结转

**处理对象**：科目编码以5开头的费用类科目

**结转规则**：
- 借方余额（费用类）：借记目标科目，贷记费用科目
- 贷方余额（收入类）：借记费用科目，贷记目标科目

**示例**：
```
假设：销售费用(5601) 借方余额 10,000元
结转分录：
  借：本年利润(3103)    10,000
  贷：销售费用(5601)    10,000
```

#### 第二步：本年利润结转

**处理对象**：本年利润科目（默认3103）

**结转规则**：
- 将本年利润科目的余额结转到未分配利润科目（默认310415）

**示例**：
```
假设：本年利润(3103) 贷方余额 50,000元（盈利）
结转分录：
  借：本年利润(3103)      50,000
  贷：未分配利润(310415)  50,000
```

#### 第三步：以前年度损益调整

**处理对象**：以前年度损益调整科目（默认6000）

**结转规则**：
- 将以前年度损益调整科目的余额结转到指定的结转科目（默认310415-未分配利润）

**示例**：
```
假设：以前年度损益调整(6000) 借方余额 5,000元
结转分录：
  借：未分配利润(310415)        5,000
  贷：以前年度损益调整(6000)    5,000
```

### 3.3 结转周期说明

| 结转周期 | 说明 | 适用场景 |
|---------|------|---------|
| 按月结转 | 每月月末自动结转损益 | 适合需要按月查看经营成果的企业 |
| 按年结转 | 每年年末自动结转损益 | 适合只需要年度汇总的企业 |

### 3.4 结转方式说明

| 结转方式 | 说明 | 适用场景 |
|---------|------|---------|
| 追加结转 | 在原有结转基础上追加新的结转 | 适合分期结转，保留历史记录 |
| 重新结转 | 删除原有结转重新生成 | 适合需要重新计算的情况 |

### 3.5 凭证分类说明

| 凭证分类 | 说明 | 生成凭证数量 |
|---------|------|-------------|
| 收益与损益分开结转 | 收入类和费用类分别生成凭证 | 生成2张凭证 |
| 收益与损益同时结转 | 收入类和费用类合并生成凭证 | 生成1张凭证 |

### 3.6 借贷方设置说明

| 设置选项 | 说明 | 适用场景 |
|---------|------|---------|
| 按科目方向反向结转 | 当余额与科目方向不一致时，按科目默认方向的反向结转 | 适合严格按科目属性处理 |
| 按金额正数结转 | 当余额与科目方向不一致时，按金额的正数结转 | 适合按实际金额处理 |

## 5. 使用说明

### 5.1 操作入口

**菜单路径**：财务 > 期间 > 结转损益

**访问方式**：
1. 登录 Wimoor ERP 系统
2. 在左侧导航菜单中找到"财务"模块
3. 展开"期间"子菜单
4. 点击"结转损益"进入配置页面

### 5.2 配置步骤详解

#### 步骤一：设置结转周期

**操作说明**：
- 选择"按月结转损益"：系统每月月末自动执行损益结转
- 选择"按年结转损益"：系统每年年末自动执行损益结转

**推荐设置**：
- 一般企业建议选择"按月结转"，便于按月查看经营成果
- 业务简单的企业可选择"按年结转"

#### 步骤二：设置结转方式

**操作说明**：
- 选择"追加结转"：在原有结转基础上追加新的结转记录
- 选择"重新结转"：删除原有结转凭证，重新生成新的凭证

**推荐设置**：
- 日常结转建议选择"追加结转"
- 发现错误需要重新计算时选择"重新结转"

#### 步骤三：配置凭证设置

**凭证日期**：
- 点击日期选择器选择凭证日期
- 建议设置为结转期间的最后一天（如月末、年末）

**凭证字**：
- 从下拉菜单中选择凭证字
- 默认为"转"，表示转账凭证

**凭证摘要**：
- 输入凭证的摘要说明
- 默认为"结转本期损益"，可根据需要修改

**凭证分类**：
- 选择"收益与损益分开结转"：收入类和费用类分别生成两张凭证
- 选择"收益与损益同时结转"：收入类和费用类合并生成一张凭证

#### 步骤四：设置借贷方处理方式

**操作说明**：
- 选择"按科目方向反向结转"：当余额与科目方向不一致时，按科目默认方向的反向结转
- 选择"按金额正数结转"：当余额与科目方向不一致时，按金额的正数结转

**推荐设置**：
- 一般建议选择"按科目方向反向结转"
- 如有特殊需求可选择"按金额正数结转"

#### 步骤五：配置结转科目

**损益类科目结转科目**：
- 从下拉菜单中选择损益类科目的结转目标科目
- 默认为"3103 本年利润"
- 费用类科目（5开头）的余额将结转到此科目

**本年利润结转科目**：
- 从下拉菜单中选择本年利润的结转目标科目
- 默认为"310415 未分配利润"
- 本年利润科目的余额将结转到此科目

**以前年度损益调整科目**：
- 从下拉菜单中选择以前年度损益调整科目
- 默认为"6000 以前年度损益调整"

**以前年度损益调整结转科目**：
- 从下拉菜单中选择以前年度损益调整的结转目标科目
- 默认为"310415 未分配利润"

### 5.3 执行结转

**自动执行**：
- 系统在账期结算时自动执行结转
- 结转顺序：费用类科目结转 → 本年利润结转 → 以前年度损益调整结转

**手动触发**：
- 进入"账期结算"模块
- 选择需要结算的期间
- 点击"结算"按钮，系统会自动执行结转

**结转结果**：
- 系统自动生成结转凭证
- 凭证状态为"待审核"
- 可在"查凭证"模块查看生成的凭证

### 5.4 常见操作场景

#### 场景一：首次配置结转损益

**适用情况**：新系统初始化或首次使用结转损益功能

**操作步骤**：
1. 进入"结转损益"配置页面
2. 选择结转周期（建议选择"按月结转"）
3. 选择结转方式（建议选择"追加结转"）
4. 设置凭证日期为当前月末日期
5. 选择结转科目（使用默认值即可）
6. 点击"保存"按钮保存配置
7. 等待系统在账期结算时自动执行

#### 场景二：按月结转损益

**适用情况**：需要按月查看经营成果的企业

**操作步骤**：
1. 选择"按月结转损益"
2. 选择"追加结转"
3. 设置凭证日期为月末日期
4. 选择结转科目
5. 保存配置
6. 系统在每月月末自动执行结转

#### 场景三：按年结转损益

**适用情况**：业务简单，只需要年度汇总的企业

**操作步骤**：
1. 选择"按年结转损益"
2. 选择"追加结转"
3. 设置凭证日期为年末日期
4. 选择结转科目
5. 保存配置
6. 系统在每年年末自动执行结转

#### 场景四：重新结转损益

**适用情况**：发现结转错误，需要重新计算

**操作步骤**：
1. 选择"重新结转"
2. 确认删除原有结转凭证
3. 系统会重新生成新的结转凭证
4. 检查新生成的凭证是否正确

**注意事项**：
- 重新结转会删除原有凭证，请谨慎操作
- 建议在重新结转前备份数据

#### 场景五：修改结转科目配置

**适用情况**：需要更改结转目标科目

**操作步骤**：
1. 在"损益类科目结转科目"下拉菜单中选择新科目
2. 在"本年利润结转科目"下拉菜单中选择新科目
3. 点击"保存"按钮保存配置
4. 下次结转时将使用新的科目配置

## 6. 常见问题与解决方案

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 结转后凭证不平衡 | 科目余额计算错误 | 检查科目余额是否正确，重新执行结转 |
| 未生成结转凭证 | 损益类科目余额为零 | 确认损益类科目是否有余额 |
| 结转科目选择错误 | 配置错误 | 修改配置后重新执行结转 |
| 凭证日期错误 | 日期设置不当 | 修改凭证日期后重新执行结转 |
| 收入类科目未结转 | 系统只处理5开头费用类科目 | 这是系统设计，收入类科目不在结转范围内 |
| 结转失败 | 会计期间已关闭 | 打开会计期间后重新执行结转 |

## 7. 注意事项

### 7.1 业务规则

- 结转损益只会处理科目编码以**5开头**的费用类科目
- 收入类科目（6开头）**不在**结转范围内
- 结转操作会自动生成会计凭证
- 结转凭证的数据来源标记为"结账模版生成"

### 7.2 操作限制

- 会计期间已关闭时无法执行结转
- 结转操作不可逆，需要谨慎操作
- 重新结转会删除原有凭证，请谨慎使用

### 7.3 数据安全

- 结转操作会记录操作日志
- 结转凭证支持审核流程
- 建议在结转前备份数据

### 7.4 性能提示

- 数据量较大时，结转操作可能需要较长时间
- 建议在业务低峰期执行结转操作
- 如果结转失败，请检查系统日志排查问题
